# 2026-10-16

## 烟雾遮挡视线：把老版本的「爆点与实体解耦」迁回新版本

**背景**：`Bot::IsLineBlockedBySmoke`（`src/weapons.cpp`）算法优秀（球-线段相交求弦长：二次方程判别式 + `[0,1]` 夹紧，
自动覆盖端点在云内/外的各种情形），但数据源绑在存活实体上：遍历 `game_state.GetActiveGrenades()`，并过滤
`EF_NODRAW` / `FL_ONGROUND`。烟雾弹爆开后游戏 `UTIL_Remove` 删除实体（爆开前已 `EF_NODRAW`），于是
① 0.25s 的 sweep 重建（`UpdateActiveGrenade`）找不到已删实体，记录即丢失；② 实体还在时也被 `EF_NODRAW` 跳过。
结果烟雾永远挡不住 bot 视线。

**修法（保留新算法，只换数据源）**：
- `inc/constant.h`：新增 `kSmokeGrenadeLifeTime = 15.0f`（原代码库已无此常量）。
- `inc/engine.h`：新增 `SmokeCloud { pos, time }` 及 `GameState::smoke_clouds_`，配 `GetSmokeClouds()` /
  `HasSmokeClouds()` / `PurgeSmokeClouds()`。
- `src/engine.cpp`：`TrackSmokeDetonation` 额外 push `{pos, game.Time()}`（原 `smoke_detonations_` 映射保留，
  `test_game.cpp` 与 `cv_smoke_grenade_checks==1` 行为仍依赖它）；`UpdateActiveGrenade` 心跳调 `PurgeSmokeClouds()`；
  `RoundStart` 一并清空。
- `src/weapons.cpp`：改遍历 `smoke_clouds_`，逐条按寿命跳过已消散云，**完全去掉** `EF_NODRAW`/`FL_ONGROUND`/存活实体依赖；
  弦长算法与 `0.35f * smoke_radius` 阈值原样保留。

**环境/验证**：本地无 cmake/ninja/MSVC，**无法编译验证**；已 `git submodule update --init`（`ext/ystl`、`ext/linkage`）。
`tests/host/host_main.cpp:32` 设 `set_fork_per_case(true)`，每用例独立进程，烟雾云不会跨场景泄漏。
现有 `test_weapons.cpp:918-932` 与新实现一致（云在 (200,0,0)、r=240：视线穿云 chord=400 > 84 判挡；偏移 500 不挡）。
`ystl::Array` 只有 `erase(size_t,size_t)` / `erase_if(pred)` / 模板化 `operator[]`，`Array` 为 `NonCopyable`。
